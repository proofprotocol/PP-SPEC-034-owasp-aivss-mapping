# Contributing

The Proof Protocol specifications are not accepting contributions at this time.

This includes pull requests, issues proposing changes to specification text, and
derivative versions. The specifications are licensed CC BY-ND 4.0: you may share
and cite them with attribution, but you may not distribute modified versions.

To report an error or request clarification, contact craig@hackerverse.ai.

To cite this specification, see CITATION.cff.

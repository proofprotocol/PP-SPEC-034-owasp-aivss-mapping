This repository contains the Proof Protocol mapping from **OWASP AIVSS** to Proof of Efficacy evidence.

Documents how an AIVSS-scored AI vulnerability or risk can be used to select, prioritize, and contextualize Proof Protocol efficacy testing without replacing AIVSS scoring.
